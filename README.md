# Eclipse 🌑

A modern full-stack social media platform for CodeAlpha Task 2.

## Features
- Registration and login
- User profiles
- Create posts
- Like/unlike posts
- Comments
- Follow/unfollow users
- Discover/search users
- MongoDB database
- REST API
- Responsive dark UI

## Stack
HTML, CSS, JavaScript, Node.js, Express.js, MongoDB, JWT, bcrypt.

## Run
1. Install Node.js and MongoDB.
2. Open this folder in VS Code.
3. Run `npm install`.
4. Copy `.env.example` to `.env` and set `JWT_SECRET` if desired.
5. Run `npm start`.
6. Open `http://localhost:5000`.

Repository suggestion: `CodeAlpha_Eclipse`

Never commit `.env` or secrets.
